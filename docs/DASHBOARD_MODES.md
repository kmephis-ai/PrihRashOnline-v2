# Режимы дашборда доходов

Версия контракта: **0.6.0**.

## Назначение

Лист `14 Аналитика` работает как набор отдельных экранов. Переключение режима изменяет только видимость строк и положение активной области. Год, месяц, формулы, диаграммы и финансовые операции не изменяются.

## Девять режимов

| Режим | Видимые блоки | Строки |
|---|---|---|
| Обзор | Executive-экран, KPI и выбранный месяц | 10–75 |
| По годам | Блок 1 | 10–25 |
| По месяцам года | Блок 2 | 26–52 |
| Выбранный месяц | Блок 3 | 53–75 |
| Структура и стабильность | Блоки 4–6 | 220–321 |
| Операции | Блок 7 и детализация 13 | 322–381, 541–690 |
| Прогноз | Блоки 9–10 | 401–461 |
| Качество данных | Блок 8 | 382–400 |
| Полный дашборд | Блоки 1–13 | 10–700 |

Строки 1–9 — единая панель управления и всегда остаются доступными.

## Защитные условия

Перед переключением контроллер проверяет точные заголовки всех 13 разделов. При изменении структуры выполнение останавливается до обновления карты диапазонов.

Дополнительные гарантии:

- используется блокировка документа;
- сначала сбрасывается старая видимость, затем показываются диапазоны выбранного режима;
- значения года `A7` и месяца `D7` сравниваются до и после операции;
- `01 Операции` не открывается для записи;
- новые листы не создаются;
- последнее выбранное представление сохраняется в пользовательских свойствах.

## Интеграция

1. Развернуть `DashboardModeService.js` в связанном Apps Script-проекте.
2. Один раз выполнить `prhInstallDashboardModes()`.
3. Из единственного проектного обработчика `onEdit(e)` вызвать `prhHandleDashboardModeEdit(e)`.
4. Для меню и графических кнопок использовать функции `prhDashboardOverview()`, `prhDashboardYears()` и остальные публичные команды.

До развёртывания Apps Script в DEV-книге используется безопасный режим `Полный дашборд`, поэтому ни один аналитический раздел не скрыт.
