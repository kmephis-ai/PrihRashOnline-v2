# Apps Script DEV deployment

The deployment target is the container-bound Apps Script project of the spreadsheet `ПрихРасхOnline v2 DEV`.

## Required repository secrets

- `APPS_SCRIPT_ID` — Script ID from Apps Script → Project Settings.
- `CLASPRC_JSON` — complete JSON generated by `clasp login` and stored as a GitHub Actions secret. Never commit this value or paste it into issues or chat.

## One-time authorization

1. Install Node.js and run `npx @google/clasp login` on a trusted local computer.
2. Complete Google authorization under the account that owns the DEV spreadsheet.
3. Add the content of the local `~/.clasprc.json` file as repository secret `CLASPRC_JSON`.
4. Open the spreadsheet → Extensions → Apps Script → Project Settings and add the Script ID as repository secret `APPS_SCRIPT_ID`.

## Deploy

Run GitHub Actions workflow `Deploy Apps Script DEV` on branch `agent/dashboard-ux-structure`, or push a root-level `.js`/`.html` change to that branch.

The workflow validates secrets, builds `.clasp.json` only inside the runner, verifies the deployment payload, and executes `clasp push --force`.

## Post-deployment verification

1. Reopen the spreadsheet.
2. Confirm menu `ПрихРасхOnline` appears.
3. Run `ПрихРасхOnline → Настройки → Проверить структуру дашборда`.
4. Verify all 9 modes, 13 sections, 20 charts, and the Sidebar.
5. Confirm `01 Операции` was not modified.

Deployment is fail-closed: absence of either secret must stop the workflow before any push.
