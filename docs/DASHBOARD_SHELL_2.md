# Dashboard Shell 2.0

## Назначение

Dashboard Shell 2.0 превращает верхнюю область `14 Аналитика!A1:T9` в устойчивую прикладную оболочку целевого дашборда доходов.

## Состав блока

- тёмная брендовая шапка и подзаголовок;
- единая горизонтальная навигация из 10 визуальных вкладок;
- карточки выбранного года, месяца, текущего периода, количества операций и качества данных;
- подсветка активного режима;
- сохранение пользовательского режима через `UserProperties`;
- восстановление режима при повторном открытии таблицы;
- закрепление первых 9 строк и скрытие сетки;
- безопасное обновление оболочки без изменения расчётных секций.

## Безопасность

Сервис:

- не изменяет `01 Операции`;
- не изменяет финансовые значения и формулы;
- не удаляет строки, столбцы, листы или диаграммы;
- форматирует только `A1:T9`;
- проверяет сохранность выбранного года и месяца до и после применения;
- fail-closed останавливается при нарушении структуры навигации.

## Жизненный цикл

1. `onOpen` создаёт единое меню и восстанавливает Shell 2.0.
2. `DashboardModeService` показывает только диапазоны выбранного режима.
3. Shell подсвечивает активную вкладку.
4. `onEdit` синхронизирует оболочку при изменении `E3`.
5. Команда `ПрихРасхOnline → Настройки → Установить Dashboard Shell 2.0` повторно применяет оболочку идемпотентно.

## Границы Блока 1

В Блок 1 входит оболочка, режим `Обзор`, навигация и сохранение контекста. Разделение сезонности и структуры на самостоятельные аналитические экраны, а также переработка внутренних секций выполняются в Блоке 2.
